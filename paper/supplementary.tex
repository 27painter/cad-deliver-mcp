\title{Supplementary Material for: Abstention Is Not a Pass: Pre-Delivery Verification for LLM-Generated CAD Drawings}

\keywords{CAD drawing verification, drafting layer ontology, deterministic rules, query-level taxonomy, SolidWorks COM automation}

\begin{abstract}
This supplementary document provides complete reference tables and commercial CAD automation reproducibility details accompanying the main manuscript: (S1) capability boundaries of representative commercial and local CAD standards checkers, (S2) the full seven-role mechanical drafting layer ontology with GB/T--ISO--ASME clause cross-walks and the consolidated six-rule threshold specification, (S3) per-case closed-loop self-repair tool calls across query levels and drawing scales, and (S4) exhaustive SolidWorks 2025 export API/registry/preference verification together with {\upshape\texttt{.NET}} interop reflection and AutoCAD 2025 COM harness details.
\end{abstract}

\subsection{Reproducible \texttt{.NET} Interop Reflection and COM Harness Configuration}\label{sec:supp_reflection}

To guarantee script reproducibility where COM type libraries failed (\texttt{win32com.\allowbreak client.\allowbreak gencache.\allowbreak EnsureDispatch} and \texttt{makepy} both errored with \texttt{"Could not locate a type library"}), we adopted direct reflection over installed \texttt{.NET} interop assemblies rather than relying on outdated documentation. Reflecting \texttt{SolidWorks.\allowbreak Interop.\allowbreak swconst.dll} extracted all 818 \texttt{swUserPreference\allowbreak Toggle\_e} constants and authoritative COM signatures: establishing \texttt{InsertModel\allowbreak Annotations3} as 6-argument (7 arguments fail with invalid parameter count), \texttt{CreateLayer2} as 7-argument, \texttt{swUnitsLinear = 47} (not~49, which sets decimal places), \texttt{byref} outputs on \texttt{ISheet.\allowbreak GetSize}, and property-rather-than-method bindings on \texttt{GetType} and \texttt{GetProperties2}. Similarly, AutoCAD~2025 automation requires explicit \texttt{VARIANT(\allowbreak VT\_ARRAY | VT\_R8, \allowbreak tuple(...))} wrappers on double arrays (raw Python lists fail with \texttt{DISP\_E\_\allowbreak BADPARAMCOUNT}), \texttt{IAcadLayout.\allowbreak Canonical\allowbreak MediaName = "psk:ISOA3"} for paper format, and exponential backoff on \texttt{HRESULT -2147418111}. Together with zero post-processing and frozen configurations, these metadata-verified harnesses ensure full auditability across all 30 commercial exports.
